This file is no longer used.

Earlier versions of this eval (v1/v2) pasted both source documents into a
static prompt template here, in full, on every request. As of the RAG
version, the prompt is built dynamically per-question by
scripts/promptfoo-prompt.js: it embeds the question, retrieves the most
relevant chunks from docs/embedding-index.json, and builds the prompt from
only those chunks. See promptfooconfig.yaml (the `prompts:` key) and the
README for details.

This file is kept only so old links/history don't 404. It is not referenced
by promptfooconfig.yaml.
